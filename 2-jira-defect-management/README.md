# Agile Defect Lifecycle Management (Jira)

## Project Overview
This project explores the practical application of the Software Testing Life Cycle (STLC) and Agile bug tracking using Jira Software. It demonstrates the end-to-end process of triaging, documenting, and resolving a full-stack defect in a simulated Agile environment.

## What Was Explored & Implemented
* **Custom Agile Workflow:** Configured a 5-stage Kanban board (`To Do` -> `In Progress` -> `In Review` -> `Ready for QA` -> `Done`) to reflect a realistic cross-functional workflow between QA and Development teams.
* **ISTQB-Standard Bug Reporting:** Authored a highly detailed defect ticket focusing on a WebRTC video signaling failure. The report includes structured environment specs, exact reproduction steps, expected vs. actual results, and severity/priority categorization.
* **Full-Stack Defect Simulation:** Tracked a complex bug involving a React.js frontend and a Supabase backend, specifically documenting a WebSocket connection drop (`502 Bad Gateway`) caused by a UI permissions race condition.
* **Lifecycle Management & Triage:** Simulated the complete defect resolution communication loop, including developer root-cause analysis, staging environment deployment, QA regression testing, and final ticket sign-off. 

## Artifacts Included
*  Visual proof of the customized Agile workflow configuration.
*  The exported Jira ticket displaying the ISTQB formatting and the timestamped Developer-QA audit trail.
